# frame-commons

Open-source parts for the Valve Steam Frame that fit together.

People are building great things for the Frame: camera access, hand and eye tracking,
desktops, voice input. Many projects need the same pieces, and each builds its own.
frame-commons aims to be a neutral place for the shared ones: a catalog of what exists, short
specs for how parts connect, a record of what each headset update broke, and, in time, parts
built to those specs.

- **[catalog](https://github.com/frame-commons/catalog)**: the Frame projects we've found so far,
  sorted by what they provide, rebuilt weekly, also as `catalog.json`.
- **[`steam-frame.yml`](https://github.com/frame-commons/catalog/blob/main/spec/steam-frame-yml.md)**:
  a two-line file your repo can carry to describe itself and record which headset versions
  you tested.
- **[compatibility](https://github.com/frame-commons/catalog/blob/main/COMPAT.md)**: what
  works on which SteamOS and SteamVR version, built from those records as projects add them.

You don't need to join anything to be listed or to use any of it.
